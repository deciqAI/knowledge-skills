# Sources — aeo-answer-engine-optimization

> *Primary sources for the [aeo-answer-engine-optimization](../SKILL.md) skill. All URLs checked October 2026.*

- **Google Search Central. "Featured snippets and your website."** Defines featured snippets as results where the descriptive snippet comes first, notes they also appear in "People Also Ask," and states a site cannot mark its page as a featured snippet ("You can't"); Google's systems decide. https://developers.google.com/search/docs/appearance/featured-snippets
- **Sullivan, Danny. "A reintroduction to Google's featured snippets." Google, January 30, 2018.** Primary source for the case study: the January 2014 launch, the usefulness for mobile and voice, spoken answers citing the source, and the "Romans tell time at night," "reptiles good/bad pets" and 2017 "Obama coup" failures, with Google's explanations (near-match, phrasing alignment, insufficient authority weighting). https://blog.google/products/search/reintroduction-googles-featured-snippets/
- **Mueller, John. "Changes to HowTo and FAQ rich results." Google Search Central Blog, August 8, 2023.** FAQ rich results limited to "well-known, authoritative government and health websites"; How-To limited to desktop; unused structured data "does not cause problems for Search, but also has no visible effects." https://developers.google.com/search/blog/2023/08/howto-faq-changes
- **Google Search Central. "Latest Google Search documentation updates" (changelog).** September 2023: How-to documentation removed because the rich result "is no longer shown in search results, on both desktop and mobile." May 2026: deprecation notice saying the FAQ rich result "will no longer appear in Google Search starting May 7, 2026," with the FAQ documentation removed afterward. The old FAQPage documentation URL now redirects here. https://developers.google.com/search/updates
- **Google Search Central. "General structured data guidelines."** "Don't mark up content that is not visible to readers of the page." Source for the schema-matches-visible-content gate. https://developers.google.com/search/docs/appearance/structured-data/sd-policies
- **Google Search Central. "Introduction to structured data markup in Google Search."** Google uses structured data "to understand the content of the page." Source for "schema aids machine understanding, not display." https://developers.google.com/search/docs/appearance/structured-data/intro-structured-data
- **Google Search Central. "Speakable (BETA) structured data."** Marks sections "best suited for audio playback using text-to-speech." Still labeled beta. https://developers.google.com/search/docs/appearance/structured-data/speakable
- **Google Search Central. "Creating helpful, reliable, people-first content."** Google's baseline content-quality guidance, which AEO structure sits on top of. https://developers.google.com/search/docs/fundamentals/creating-helpful-content
- **Schema.org vocabulary:** FAQPage https://schema.org/FAQPage · HowTo https://schema.org/HowTo. Vocabulary definitions only; whether any engine *displays* a type is set by that engine's documentation.

**What is NOT cited and why:** the "roughly 40–60 words" answer-first length is a common practitioner heuristic, not a published specification, and is labeled as such in the skill. No snippet-selection-rate or click-through statistics are cited. The 97.4% accuracy figure in Sullivan (2018) is a third-party test reported by Google and is not relied on here. Rich-result availability changes over time; the skill tells the running agent to check Google's live documentation and not answer from memory.
